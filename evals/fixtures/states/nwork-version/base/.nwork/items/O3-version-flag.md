# O3: A version flag

Status: active
Validity: current
Topics: cli, version

## Outcome

`python3 -m textkit --version` prints the version of textkit, so that users can say which version they run when they report a problem.

## Out of scope

- Any other new option or command.
- Changing how the version number is set in `pyproject.toml`.
